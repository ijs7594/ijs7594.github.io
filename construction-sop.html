📅 軟性開幕之後（不用再按天看）

過了軟性開幕，「第幾天」對人來說已經沒有感覺了，接下來這樣走就好：

軟性開幕 → 試營運（真實抓出問題、調整動線） → 開幕促銷週（每人3碗特價活動） → 正式開幕。實際天數看下方 WBS 表。

關鍵提醒

🎯 要徑（0浮時，完全不能拖）

簽約 → 聯合現場丈量勘查 → 各工班報價排班 → 拆除進場 → 丈量報價 → 木工進場 → 玻璃工程（跟木工同期，不等鐵工）／水電施工／油漆 → 鐵工 → 地板 → 監控音響裝機 → 延誤緩衝 → 全功率試車 → 驗收 → 試營運 → 開幕促銷週。天數以下方 WBS 表為準。

⚠️ 延誤風險點

  • 玻璃要在拆除完就先估尺寸開始生產，等鐵工完工才開始等於平白多花時間（詳見下方 KNOW-HOW）
  • 玻璃設計定案前要先讓廠商確認結構安全可行性，不是只確認尺寸（詳見下方 KNOW-HOW）
  • 廚房設備下單觸發點要提前到加盟合約簽定，不是等租約簽約日（詳見下方 KNOW-HOW）
  • 淘寶來的設備／家具常卡在最後幾天到貨，這是延誤緩衝的主要來源，目標是壓到0（詳見下方 KNOW-HOW）

🤝 協調重點

  • 玻璃工程要提前跟廠商溝通：先用拆除後的粗估尺寸下單生產，最後現場微調再等鐵工，且設計階段就要問清楚結構安全性
  • 各工班進場前需完成圖面確認與現場交底，避免重工與等待
  • 冷氣、招牌都有浮時，優先順位可以排在要徑項目之後
  • 人員招募要跟工程同步啟動，不要等工程快完工才想到找人，不然人員訓練會變成真正的瓶頸

✅ 完成目標

  • 完成試車＋驗收＋職能認證考核後，軟性開幕／試營運開始
  • 試營運結束、開幕促銷週跑完，等於正式開幕

為什麼要這樣排（KNOW-HOW 對照——唯一詳細解釋來源，其他地方只提醒有這件事）

為什麼要先場勘？

簽約前先場勘，是為了確認樑柱、給排水、電力容量等硬體條件符不符合開店需求，也才能抓出拆除與裝潢的大概範圍與天數。

為什麼簽約後要辦一場「聯合現場丈量勘查」？該找誰來？

簽約當天就找木工、水電、弱電、拆除、輕鋼架、招牌、地板、冷氣、台電、遮雨棚、斜坡鐵工、負責畫設計圖的丈量人員全部一起到現場看一次，讓每個工班用同一份現場狀況去抓自己的粗估報價跟排班，不用各自約時間、各講各的、資訊兜不起來。玻璃、鐵工、油漆、廚房設備商也建議一起叫來——雖然隔間還沒拆、他們現場評估不出真正的施作安排，但先讓他們熟悉環境，之後排程會更順。房東或管委會要不要到場則看情況（有涉及外觀、招牌位置變動時比較需要）。這場是初步的共同認知，不是最終精確丈量——精確的尺寸還是要等拆除完現場淨空後才抓（見下一條）。

舊玻璃門、舊招牌要在簽約前先評估

能不能沿用，直接影響裝潢預算跟拆除範圍。簽約後才發現不能用，重做成本跟時間都會被打亂。

為什麼拆除完才約木工水電丈量報價？

拆除前現場還有舊隔間擋著，管線走向、樑柱位置都看不清楚。太早丈量，抓的是不準的數字。

為什麼台電外接電要簽約當天就申請？

電力公司拉線進來大概要 1-2 週，是店家自己完全排不上的外部時間，晚申請不會因為你趕工就變快。簽約當天跟招牌、設備一樣馬上申請，才不會卡在最後全功率試車那一關。

設備要10天內交貨，是不是要放棄淘寶採購？

不是。真正該改的是「叫貨的觸發點」，不是採購管道。淘寶的長途海運本來就要花時間，但這段時間不需要等到「這家店簽租約」才開始算——加盟合約／合夥人合約／經理人合約一簽，總部就篤定這家店一定會開，可以馬上跟淘寶叫貨到集運商倉庫備著，這段長途運輸是跟「找地點」同步進行、不佔用「簽約後」的時鐘。等真的找到地點簽了租約，貨已經在集運倉等著，剩下集運倉到新店這段才是真正影響開店時程的「10天以內」。這是總部要不要建立常態庫存管理機制的問題，不是要不要用淘寶的問題。

為什麼人員招募要簽約當天就啟動，不是等工程快完工才找？

訓練跟認證需要時間（基礎人員10-12天、主管5-7天），如果等工程完工才開始招募，人員訓練會變成整條時程最後、也最沒人注意的瓶頸——工程準時完工，但沒有訓練好的人可以上線，一樣沒辦法準時軟性開幕。目標是工程正式啟動前，人就已經找齊、開始待訓，讓「工程」跟「人」兩條線並行推進，最後在職能認證考核那一關會合。

為什麼輕鋼架不能跟拆除同時進場？

輕鋼架是做天花板骨架的另一組工班，拆除現場還有清運中的雜物、鋭利邊角，這時候讓輕鋼架師傅進來施工，容易割傷手。要等拆除完、現場淨空之後才能讓輕鋼架進場，雖然都排在同一週，順序還是要分開。

水塔為什麼要跟招牌一起裝？

招牌安裝通常需要吊車把招牌吊到定位，這台吊車來一次不便宜。如果店裡也要裝水塔（例如樓上有出租給住戶要用水），可以排在同一天，用同一台吊車把水塔一起吊上去，省下再叫一次吊車的費用跟協調時間。

為什麼斜坡鐵工要排在水電施工完成之後？

水電施工期間，電線常常會暫時外露在地面上。等水電工程做完，才用斜坡鐵工把地上的電線蓋起來、做成不會絆倒人的斜坡，這樣既保護電線不被踩踏破損，也避免現場人員被電線絆倒受傷。太早裝，水電之後還要動線，反而會把剛做好的斜坡弄壞。

為什麼油漆要在鋪地板之前？

油漆會噴濺、有粉塵，地板先鋪好容易弄髒刮傷，事後重新拋光更花錢費工。

為什麼設備要等地板鋪完才能進場？

餐飲設備通常很重，需要在平整完工的地面上定位抓水平。地板沒鋪完就搬設備進場，可能壓壞底材。

玻璃到底要不要等鐵工完工？

不是整段都要等——玻璃廠商可以用拆除後的粗估尺寸提前開始生產（實務上跟木工同期就能動工），只有最後現場「精確丈量＋裝門」那一步，才需要等鐵工把門框骨架定案，這樣玻璃尺寸才對得上。把整段生產都排在鐵工之後會平白拖長將近 2 週。

為什麼玻璃設計定案前要先確認結構安全，不是只確認尺寸？

尺寸量得出來，不代表結構做得出來——大面積無框玻璃、特殊懸空設計，廠商可能在最後現場丈量時才發現無法確保安全而拒做。富國店就遇到這個狀況。設計階段就該把設計圖拿給玻璃廠商過目確認可行，不要等到最後一刻才發現要改設計，臨時改動會直接衝擊已經排好的安裝時程。

水電為什麼要進場 2～3 次？

評估：跟拆除同期確認用電安全。粗胚：封牆前把插座迴路管線預埋好。精修收尾：設備定位後回來做最後微調與全功率試車。

為什麼冷氣要找兩家廠商評估？

噸數、安裝位置、管線走法、報價，兩家一比就知道有沒有漏算或坑錢的地方。

為什麼監視器、音響要等五金定位、桌椅都差不多才裝？

鏡頭角度、喇叭擺位都要對應「最終」的空間格局。太早裝好，之後家具一擺，鏡頭可能被擋、音響效果也會被家具吸音改變。

為什麼設備要「同時全功率」運轉測試？

分開開機只能確認單一設備能不能動，看不出同時使用時的總用電量，測不出電力總容量夠不夠。

為什麼要抓「試營運」，不直接開幕？

備料、出餐、清洗、收銀的動線，只有真實客人上門才會暴露問題。試營運期間出的包還有時間修，留到開幕當天代價高很多。

為什麼設備裝機完成後，還要抓一段「延誤緩衝」才試車？

富國店實際發生的狀況：玻璃廠商最後一刻說設計不安全要重新設計、部分淘寶設備（工作台冰箱、電磁爐）晚到、買的桌子還要等水電幫忙裝好。這段不是標準工期的一部分，是非常態——顧問的方向是把目標壓到0（例如設備叫貨觸發點提前、玻璃設計提前確認安全性），真的發生要提前告知加盟業主，不要用「反正本來就會delay」的心態排時程。這裡留著這一列，是誠實記錄富國店真實發生過的狀況，讓下一次展店知道這些坑在哪，不是鼓勵大家把它當標準流程照抄。
